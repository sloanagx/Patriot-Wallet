# Patriot Wallet

Patriot Wallet is a secure, cross-platform cryptocurrency wallet for Windows and macOS. Built by Americans, for Americans.

## Supported Assets

- Bitcoin (BTC)
- Ethereum (ETH)
- Dogecoin (DOGE)
- Solana (SOL)
- Tether (USDT)
- USD Coin (USDC)
- Monero (XMR)

## Features

- Native support for Bitcoin, Ethereum, Dogecoin, Solana, Tether, USD Coin, and Monero
- Easy wallet setup and recovery
- Secure key storage on Windows and macOS
- Transaction history and balance tracking
- Send and receive crypto with a clean interface
- SHA-256 Encryption

## Platforms

- Windows
- macOS

## Getting Started

1. Download Patriot Wallet for your platform.
2. Install the application.
3. Create a new wallet or recover an existing one using your seed phrase.
4. Add funds and manage your supported assets.

## Security

Patriot Wallet is built with security in mind. Private keys are stored locally and never shared externally.
